# PROMO

Лендинг «Больше возможностей для жизни».

## Запуск

Сайт статический, сборка и установка зависимостей не требуются.

```bash
python3 -m http.server 8080 --directory dist
```

Откройте http://localhost:8080.

## Файлы

- `dist/index.html` — страница, стили и интерактивность.
- `dist/background.png` — фоновые изображения.
- `dist/reference.png` — исходный макет и графика брендов.

Для размещения на статическом хостинге используйте каталог `dist`.

Реализованы поиск, фильтрация и просмотр предложений. Вход, оплата и оформление покупки не подключены.
